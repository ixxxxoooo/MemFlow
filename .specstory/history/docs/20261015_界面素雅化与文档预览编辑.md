# 界面素雅化与文档预览编辑

> @author ygw　　日期:2026-10-15

## 需求
1. 配色素雅化,提高按钮文字清晰度。
2. 流程图只在用户明确要求时输出。
3. 修复 AI 输出时的双光标。
4. 时间流标签区不再横向滚动。
5. 知识库文档弹窗预览,Markdown 所见即所得并支持在线编辑。
6. 评估导入文档用 AI 解读还是直接索引。

## 结论与实现
- **双光标原因**:内容为空时 `Markdown` 与「正在检索并思考」各渲染一个闪烁 `▍`,加上输入框原生光标。现改为单一不闪烁的呼吸圆点,生成中输入框光标透明。
- **导入策略**:文档默认快速索引(分块 + 向量 + FTS,摘要取正文开头),不调用 LLM;检索质量基本不变,速度大幅提升。AI 解读按需触发:队列模式 `reindex_ai` / `ingest_ai`,或设置项 `docAiEnrich`。笔记、图片仍走 AI 提取(内容短,标签驱动时间流)。
- **按需出图**:`prompts::wants_diagram` 关键词判定,`chat_system_prompt(today, context, allow_diagram)`。
- **文档弹窗**:`DocModal`,三种渲染/编辑方式 —— md 所见即所得(Milkdown Crepe,按需懒加载)、txt 纯文本编辑、pdf/docx 仅预览。编辑内容以数据库为准,原附件文件不改动。
- **与计划的差异**:快速索引不改写文档标题(列表仍展示文件名),仅生成摘要;txt 编辑使用纯文本框而非富文本,避免 Markdown 转义改变原文。
